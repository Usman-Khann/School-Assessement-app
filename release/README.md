# Android app

- **SchoolAssessment-v2.1.0-arm64.apk**: for almost all phones from the last ~8 years.
- **SchoolAssessment-v2.1.0-older-phones-armv7.apk**: only if the first one says "app not installed" on an old phone.

Open the file on the phone and allow installing from this source. This is a test build signed with a development key.
